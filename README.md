# ESP32-S3 контроллер полива (TFT + энкодер)

## Что изменено по вашему запросу

- Шрифт на основном экране увеличен (`TextSize=2`) и информации меньше: в списке зон показывается только самое важное (`Zone`, `время работы`, `ON/OFF`).
- На главном экране добавлены видимые кнопки/панель действий: `START`, `STOP`, `AUTO`.
- При нажатии на зону открывается **отдельное подменю** зоны (увеличенный шрифт), где меняются:
  - `Enabled`
  - `Start`
  - `Stop`
  - `Duration`
  - `Days/Period` (пресеты)
- Добавлен явный индикатор состояния насоса (`PUMP:ON/OFF`) в шапке экрана.
- Улучшена обработка энкодера: заменено на отдельный фильтр с таблицей переходов, антидребезгом и детент-порогом.
- Добавлена логика минимизации мерцания: полный redraw только при изменениях UI, в фоне обновляется только динамика шапки (время/насос/auto).
- Код разбит на несколько файлов:
  - `firmware/esp_irrigation_controller.ino`
  - `firmware/encoder_filter.h`
  - `firmware/time_tools.h`
- Веб-интерфейс оставлен и расширен под настройку зон и времени.
- Добавлена отдельная страница редактирования каждой зоны (`/zone?z=<n>`) с кнопками изменения параметров.
- Добавлен блок удалённого доступа через Tailscale (`/tailscale/on`, `/tailscale/off`, `/tailscale/set?host=...`).

## Управление с экрана

### Главный экран

- Вращение: выбор зоны в списке (когда выделен список).
- Долгое нажатие: переключает фокус `СПИСОК <-> КНОПКИ START/STOP/AUTO`.
- Когда выделены нижние кнопки: вращение выбирает кнопку, короткое нажатие выполняет действие.
- Короткое нажатие на зоне: вход в подменю выбранной зоны.
- Очень долгое нажатие (или двойной короткий клик): `Stop`.

### Подменю зоны

- Вращение: выбор поля.
- Короткое нажатие:
  - на обычном поле: вход/выход в режим редактирования,
  - на `Run now`: немедленный запуск зоны,
  - на `Back`: выход в главный экран.
- В режиме редактирования вращение изменяет значение.
- Долгое нажатие в edit-режиме: переход к следующему полю.

`KEY0` — аварийный стоп.

## Время без интернета

- При наличии Wi‑Fi время синхронизируется через NTP.
- Без интернета время можно выставить вручную:
  - Serial: `time set YYYY-MM-DD HH:MM:SS`
  - Web: `/settime?y=2026&mo=2&d=18&h=14&mi=30&s=00`
- Часовой пояс:
  - Serial: `tz <minutes>`
  - Web: `/tz?min=180`

> Важно: без внешнего RTC ESP32 не сохраняет точное время после полного выключения питания.

Рекомендованный модуль RTC: **DS3231**.

## Расширение зон (+12 и больше)

Для расширения количества зон сверх GPIO самого ESP32-S3 закажите:

1. **I/O-расширитель**: `MCP23017` (16 GPIO) или `PCF8575`.
2. **MOSFET-драйверы** для соленоидов.
3. **DS3231** для стабильного времени без интернета/после отключения питания.

## Веб-интерфейс

Откройте IP контроллера (в Serial выводится после подключения Wi‑Fi).

Поддерживается:

- `GET /startall`
- `GET /stop`
- `GET /auto/on`, `GET /auto/off`
- `GET /run?z=<n>`
- `GET /zone?z=<n>` — интерактивный редактор зоны (кнопки +/-/toggle)
- `GET /setzone?z=1&en=1&sh=6&sm=0&eh=6&em=10&dur=600&days=127`
- `GET /settime?...`
- `GET /tz?min=...`

## Доступ к контроллеру через интернет (не в локальной сети)

Надёжные варианты:

1. **VPN (рекомендуется)**
   - Tailscale / WireGuard.
   - Безопасно, без проброса портов наружу.
2. **MQTT/облако**
   - Контроллер подключается к брокеру, управление через сервер/приложение.
3. **Проброс порта + DDNS**
   - Работает, но менее безопасно; обязательно HTTPS, auth, firewall.

Практически лучший путь: **Tailscale на вашей домашней сети + web UI контроллера**.

В web UI добавлен отдельный блок Tailscale, где можно включить режим и задать tailnet host (для отображения удалённого URL).

## Пины по умолчанию

### TFT + Encoder

- TFT SCL: `12`
- TFT SDA: `11`
- TFT CS: `10`
- TFT DC: `9`
- TFT RES: `8`
- TFT BLK: `7`
- ENC A: `5`
- ENC B: `6`
- ENC BTN: `4`
- KEY0: `3`

### Выходы

- Зоны: `13,14,15,16,17,18,21,35,36,37,38,39`
- Насос: `40`

Если у вас другая разводка — измените `ZONE_PINS[]` и `PUMP_PIN`.
