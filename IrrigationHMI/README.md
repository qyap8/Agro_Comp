# IrrigationHMI (refactored architecture)

## Что изменено архитектурно

HMI больше **не управляет физическими выходами напрямую** (клапаны/насосы).
Теперь HMI выполняет роль:
- экран + UX,
- RS-485 master,
- Wi‑Fi manager,
- встроенный web server,
- discovery модулей и динамический UI каналов.

Команда управления только одна по смыслу: `SET_CHANNEL_STATE(moduleAddr, channelId, state)`.

## Навигация

Главные вкладки теперь только 3 (нижние):
- Home
- Zones
- Settings

## Dynamic Zones

Экран Zones строится динамически по инвентарю модулей:
- без hardcode 16 зон,
- каналы сгруппированы по модулю,
- при исчезновении модуля карточка удаляется.

## Wi‑Fi manager

- ввод SSID/Password с тачскрина (LVGL textarea + keyboard),
- сохранение в Preferences,
- автоподключение на старте,
- fallback AP: `Irrigation-HMI-Setup`.

## REST API

- `GET /api/state`
- `POST /api/channel`
- `POST /api/rescan`
- `POST /api/wifi`

Также есть простая встроенная web-страница из PROGMEM.

## Localization

Добавлен лёгкий слой локализации через `tr(KEY)`:
- English
- Español
- Русский
- Հայերեն

## Важно

- Инициализация дисплея/LVGL не изменялась: `Board->init(); Board->begin(); lvgl_port_init(...)`
- FreeRTOS задачи сохранены: `logic_task`, `comm_task`
- RS-485 слой сохранён

## Плавность скролла и «плавающий» экран

Чтобы уменьшить рывки:
- UI больше не пересоздаётся на каждом refresh-цикле.
- Карточки модулей/каналов пересобираются только при реальном изменении состояния (hash-проверка).
- Это существенно снижает дрожание при скролле.

Если нужно ещё плавнее:
- увеличить период `ui_refresh()` до 300-400 мс,
- для тяжёлых списков обновлять только изменившиеся элементы,
- избегать `lv_obj_clean()` в цикле без необходимости.

## Шрифты для Español / Русский / Հայերեն

Проблема с «квадратиками» — это не перевод, а отсутствие глифов в активном шрифте.

Практичное решение (без ломки структуры):
1. Сгенерировать кастомный шрифт через LVGL Font Converter.
2. Включить диапазоны:
   - Latin + Latin-1 Supplement (испанский),
   - Cyrillic (русский),
   - Armenian.
3. Подключить шрифт в проект и назначить как default для `lv_scr_act()`/базового стиля.

Минимальный fallback: оставить UI-ключи на английском для строк, где нет доступного шрифта.
